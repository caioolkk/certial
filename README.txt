CERTIAL — SITE ESTÁTICO

Publicação na Vercel:
1. Faça upload desta pasta como projeto.
2. Framework Preset: Other.
3. Build Command: deixe vazio.
4. Output Directory: deixe vazio / raiz do projeto.
5. O arquivo inicial é index.html.

Observações:
- O site não depende de framework, fonte externa ou biblioteca JS. Isso reduz carga e pontos de falha.
- O formulário da página contato.html não envia dados para servidor: ele prepara a mensagem, copia e abre o Instagram.
- Quando houver telefone/WhatsApp/e-mail oficial, os CTAs podem ser trocados rapidamente no HTML/JS.
- Atualize a Política de Privacidade caso adicione Analytics, Pixel, CRM ou formulário externo.
